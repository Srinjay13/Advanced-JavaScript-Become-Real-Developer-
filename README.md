# Advanced-JavaScript-Become-Real-Developer

A personal set of notes distilled from a Sheriyans Coding School tutorial to help you quickly review advanced JavaScript concepts. This repo is a compact reference for core topics you’ll revisit when preparing for interviews, building projects, or refreshing fundamentals.

---

### About the Notes
These notes cover four focused areas of JavaScript that are essential for becoming a confident developer:

- **Scopes, Execution Context and Closures**  
- **this keyword**  
- **Object Oriented Programming**  
- **Fetch API and HTTP Basics**

All credit goes to **Sheriyans Coding School** — these are my personal notes taken from their lecture so I can brush up later.

---

### What You Will Learn
- **Scopes and Execution Context**  
  - Global, function, and block scope; lexical scope; hoisting and the execution stack.  
  - How execution context is created and destroyed during function calls.

- **Closures**  
  - How closures capture lexical environment; practical patterns like data privacy and factory functions.

- **this keyword**  
  - How `this` is determined in different call sites: global, method, constructor, explicit binding, and arrow functions.

- **Object Oriented Programming**  
  - Prototypal inheritance, constructor functions, ES6 classes, encapsulation, and composition vs inheritance.

- **Fetch API and HTTP Basics**  
  - `fetch()` usage, promises and async/await, request/response lifecycle, common HTTP methods and status codes, and basic error handling.
